# Demo Script — PixelDev TaskForge

Target length: 75–90 seconds.

## Opening

“Hi guys, this is PixelDev TaskForge — a Feature Task Generator built for the Coding Task Factory track. It creates realistic coding tasks from a sample repository, complete with requirements, a reference solution, tests, and validation evidence.”

## Demo flow

1. Show the home screen and point to the three sample repositories.
2. Select **Shopping Cart App** and **Discount codes**.
3. Keep difficulty on **Medium**, language on **JavaScript**, and explanation on **Hinglish**.
4. Click **Generate task package**.
5. In the **Brief** tab, show the user story, Hinglish explanation, requirements, acceptance criteria, and edge cases.
6. Open the **Solution** tab and show the reference implementation.
7. Open the **Tests** tab and show feature tests plus regression checks.
8. Open the **Validation** tab and highlight the evidence: reference checks pass, and broken logic is caught.
9. Click **Download** to export the JSON task package.
10. Switch to **Notes App → Search + tags** to prove the same pipeline works for a different repo.

## Closing line

“TaskForge is reusable: change the repo or feature theme, and it generates a new testable task package with evidence. That makes it useful for evaluating AI coding systems with realistic, measurable tasks.”

## Judge points to mention

- Reusable pipeline, not one fixed task
- Reference implementation included
- Tests catch incorrect behavior
- Regression checks protect existing functionality
- JSON package makes the output portable for evaluation
